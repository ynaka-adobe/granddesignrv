# tabs-swatch

Custom **tabs** block. Purpose: paint colour picker: round swatches swap the exterior image and colour name.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per colour (any count). Cell 1: swatch image + colour name (e.g. SMOKE). Cell 2: exterior image of the unit in that colour (alt = colour name).
