# tabs-brands

Custom **tabs** block. Purpose: tabbed product browser.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: cell 1 = tab label, cell 2 = optional lead link ("All <type>") then per model: image, model name, floorplans/MSRP line, CTA link (each image starts a new model card).
