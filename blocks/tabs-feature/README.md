# tabs-feature

Custom **tabs** block. Purpose: feature tabs with rich panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per feature (1-10). Cell 1: tab label. Cell 2: free-form content (images, heading, paragraphs, lists, links). Put a standalone image first for image-beside-text, last for text-over-background-photo, alone for a full-width banner; put several logos/icons in one paragraph or list for an icon row.

No variations.
