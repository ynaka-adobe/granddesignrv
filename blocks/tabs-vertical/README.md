# tabs-vertical

Custom **tabs** block. Purpose: vertical tab list with image, title and description panel.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item (4-8). Cell 1: item label (e.g. Thermal Roof Design (R-40)*). Cell 2: optional image, H3 title, description paragraph.
