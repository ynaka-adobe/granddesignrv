# accordion-boxed

Custom **accordion** block. Purpose: FAQ-style collapsible items under a section's intro text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item, two cells: title | panel content (paragraphs, lists, links). Example items: Shipping Information, Delivery, Price & Sales Tax, Returns/ Exchanges.
