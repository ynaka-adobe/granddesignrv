# hero-model

Custom **hero** block. Purpose: model-page hero with model logo, optional award badge, starting price and two CTAs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one column, two rows. Row 1: background image. Row 2: model logo image, optional award badge image (second image), optional price paragraph ("Fifth Wheel Models Starting at $192,156"), CTA links each in its own paragraph (first = left, second = right).

## Layout

- With an award badge (second image): logo and badge share the top row, price below, the two CTAs each centred in one half (7-column grid from 900px).
- Without a badge: logo, optional tagline heading, price and CTAs stack in one 5/12 column (from 1200px), one column in from the left.

## Supported variations

Optional, for the column position of the no-badge layout on desktop (the source places it per page):

- `left`: flush left (e.g. Imagine AIM)
- `indent`: two columns in (e.g. Transcend One, Serenova)
- `right`: right half (e.g. Solitude)
