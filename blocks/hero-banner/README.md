# hero-banner

Custom **hero** block. Purpose: hero.

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one column:

- Row 1: background image, or a standalone link to a video (Scene7 `/is/content/`, `.mp4`, `.webm`, `.mov`). A video link becomes a muted, inline, autoplaying background `<video>` (it plays once, like the source; with reduced motion it shows the last frame instead).
- Row 2: optional eyebrow paragraph before the heading, heading (h1), subheading (first paragraph after the heading), body text, CTA link.

When the background is a video, the eyebrow and CTA are hidden to match the source launch hero. Image backgrounds show them and get the dark gradient shade.
