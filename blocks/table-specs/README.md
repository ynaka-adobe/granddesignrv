# table-specs

Custom **table** block. Purpose: floorplan specification comparison table.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: a table: row 1 = empty corner cell then one cell per floorplan name; rows 2..n = spec label then one value per floorplan; optional last row = empty cell then one link per floorplan (VIEW). Any number of floorplan columns.

## Supported variations

No variations.
