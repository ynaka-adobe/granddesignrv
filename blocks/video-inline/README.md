# video-inline

Custom **video** block. Purpose: click-to-play inline video with poster.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell: poster image + link to the video (Scene7 /is/content/<company>/<name>-AVS, or a direct .mp4/.webm URL). Link text is used as the accessible label when it is not a URL; otherwise the poster alt text.

## Supported variations

No variations.
